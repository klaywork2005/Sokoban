SOKOBAN (JAVA): SETUP GUIDE + CHECKLIST
=====================================================================

     mvn compile exec:java     run the app
     mvn test                  run tests


Suggested structure (you write the classes):
  src/main/java/sokoban/        Main, Dir, State, Level, LevelLoader, Game, GamePanel
  src/main/java/sokoban/solver/ Solver interface + each solver version
  src/main/resources/levels.txt level data
  src/test/java/sokoban/        tests

Design tips:
  - Use Swing (ships with the JDK, no extra setup).
  - Keep the rules in one pure function (state + direction -> new state or
    null). The solver will call the same function later.
  - Make the state immutable with equals/hashCode so it works in a HashSet.
  - Encode positions as row * cols + col.

Level file format (XSB). Blank line between levels, ";" starts a comment:
  #  wall     (space) floor     .  goal
  $  box      @  player         *  box on goal     +  player on goal
Get real levels (e.g. Microban, freely distributable with credit) for
testing and benchmarking.
